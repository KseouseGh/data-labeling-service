# 🏷️ DATA LABELING SERVICE [for chat-AI-agents]
Сервис автоматизированной разметки данных для формирования датасетов под "fine-tuning" и "training" LLM, используемых в AI-агентах для ИИ-чатов различных компаний и
 автоматизированных систем. Веб-платформа превращает неструктурированные документы регламента (PDF/DOCX/TXT) в готовые обучающие датасеты. 
Система автоматически генерирует пары "вопрос–ответ" на основе семантического поиска во внутренней RAG-системе, собирает экспертную обратную связь,
проводит валидацию ответов на противоречия через NLI, и экспортирует результат в формате JSONL.

# [*] Ключевые возможности 
# (+) Умная загрузка документов
 Парсинг PDF/DOCX/TXT, асинхронный чанкинг с сохранением границ предложений или страниц
# (~) RAG-генерация примеров
 Векторный поиск контекста + генерация Q&A через вызов LLM, провайдер OpenRouter
# (S) Безопасная авторизация
 JWT + Argon2, защита всех эндпоинтов через реализованный паттерн Dependency Injection
# ($) Сбор фидбека
 [Like]/[Dislike]/[Развёрнутый-ответ] с автоматическим обновлением
# (C) NLI-валидация (in work-progress!)
 Проверка отредактированных ответов на логические противоречия, как локально в фидбеке, так и с базой знаний, полученной из документов регламента
# (-->) Экспорт датасетов
 Готовые JSONL-файлы, могут быть использованы
# (/) Контейнеризация
 {FastAPI + AI-Service + PostgreSQL + ChromaDB + RabbitMQ + Redis} в едином контейнере, запуск происходит через docker-compose;
